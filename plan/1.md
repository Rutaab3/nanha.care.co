🔐 PHP SESSION AUTH SYSTEM
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Session variables stored after login:
  $_SESSION['user_id']
  $_SESSION['email']
  $_SESSION['full_name']
  $_SESSION['role']
  $_SESSION['avatar_url']
  $_SESSION['city']
  $_SESSION['status']

Every dashboard PHP file begins with:
  require_once '../../includes/auth_check.php';
  require_role(['admin']); // or relevant role array

auth_check.php has a require_role() function that:
  - Checks session exists and is valid
  - Checks user status != banned/suspended
  - Checks role matches allowed roles
  - On failure: redirects to /unauthorized.php 
    with flash message

Password handling:
  - PHP password_hash() with PASSWORD_BCRYPT
  - password_verify() on login
  - Never store plain text passwords

Email verification:
  - On register: generate random 64-char token, 
    store in users.email_token, send email with 
    link: /verify-email.php?token=...
  - Use PHP mail() or PHPMailer (if available)
  - Token expires after 24 hours

Forgot password:
  - Generate reset token, store with expiry 
    in a password_resets table
  - Send reset link via email

Input sanitization:
  - All $_POST and $_GET inputs through 
    htmlspecialchars() + trim() + 
    PDO prepared statements always
  - File uploads: validate MIME type, 
    extension whitelist, rename file to 
    uniqid() + extension, store in /uploads/

Rate limiting:
  - Login attempts: track in $_SESSION or 
    a login_attempts table, 5 attempts max, 
    15 min lockout

CSRF Protection:
  - Generate CSRF token per session, store 
    in $_SESSION['csrf_token']
  - All POST forms include hidden input: 
    <input type="hidden" name="csrf_token" 
    value="<?= $_SESSION['csrf_token'] ?>">
  - All API endpoints verify token before 
    processing

Role redirect after login:
  - parent → /dashboard/parent/index.php
  - babysitter → /dashboard/babysitter/index.php
  - shop_owner → /dashboard/shop-owner/index.php
  - doctor → /dashboard/doctor/index.php
  - moderator → /dashboard/moderator/index.php
  - support_agent → /dashboard/support/index.php
  - admin → /dashboard/admin/index.php

Banned user:
  - On login check: if status = 'banned' or 
    'suspended', show dedicated ban screen 
    with reason + duration, no dashboard access
